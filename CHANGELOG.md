## [1.0.0] - 2025-11-14

### Added
- Initial release of Template WebApp
- React 18 + TypeScript + Vite frontend
- Node.js + Express + TypeScript backend
- SQLite database with TypeORM integration
- ESLint and Prettier configuration
- Pre-commit hooks with Husky and lint-staged
- GitHub Actions CI/CD pipeline
- Automated deployment to GitHub Pages
- Auto-rollback on deployment failure
- Comprehensive README and documentation
- CRUD API endpoints for sample Items entity
- Responsive UI with dark/light mode support
- Development and production build scripts
- Yarn workspaces monorepo structure

### Developer Experience
- Hot Module Replacement for fast development
- TypeScript type safety across the stack
- Automatic code formatting on commit
- PR checks for code quality
- Build artifacts retention
